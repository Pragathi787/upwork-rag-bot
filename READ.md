# Upwork API Technical Support Bot

A RAG-based chatbot built using:

- Python
- LangChain
- ChromaDB
- Sentence Transformers
- DeepInfra (Llama 3.1)
- Streamlit

## Features

- PDF ingestion
- Semantic search
- Vector database retrieval
- LLM-powered question answering
- Hallucination guard
- Source display
- Latency tracking

## Run

pip install -r requirements.txt

streamlit run app.py
